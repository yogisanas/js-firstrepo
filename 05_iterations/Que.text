Method	     Purpose	                                 Returns
map()	    Transforms every element	                New array
filter()	Selects elements based on a condition	    New array
reduce()	Combines elements into a single result	    Any value


Q2. Does map() modify the original array?
No. map() creates a new array.

Q3. What happens if filter() returns true?
The element is included in the new array.

Q4. What is the purpose of the initial value in reduce()?
The initial value determines the starting value of the accumulator.

Q5. Can map(), filter(), and reduce() be chained?
Yes. Each method can pass its result to the next method.
